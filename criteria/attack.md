# Attack criteria (ATK), package mittens_attack

| ID | Level | Requirement | Proved by |
| --- | --- | --- | --- |
| ATK-001 | MUST | `attackSandbox` MUST accept `{ execute, canary }`, where `execute(program)` is any executor, MUST throw a `TypeError` when `execute` is not a function, and MUST resolve to `{ cases, breached }` with one `{ name, outcome, detail }` per attack and an outcome of "held" or "breached". | contract: the report's keys and each case's keys match exactly; a call without `execute` throws the exact message |
| ATK-002 | MUST | The suite MUST run these eight attacks under stable names: network fetch, swallowed fetch, env inspection, direct write call, synchronous loop, asynchronous loop, recursion, never-resolving promise. | contract: the list of attack names equals the exact eight-item array |
| ATK-003 | MUST | The suite MUST report an attack as breached when the canary's bytes appear in any result or error, as plain text or in base64, or when the result of the attack's program holds `escaped: true` (each program of the suite returns that when its forbidden action succeeded), MUST report an attack as held only with evidence, which is an error from the executor (it stopped the program) or a result that holds `escaped: false` (the program ran and its action was refused), so an outcome with neither and an executor that rejects are breached, and MUST report zero breaches against `mittens_sandbox` (split from the prototype's token rule, cited once in the sandbox file). | adversarial: against a fixture executor that returns its env, breached is 1 and names env inspection; against the real sandbox, breached is 0; against a fixture executor that answers every program with `{ escaped: true }`, breached is 8; against one that leaks the canary in base64, breached is 1; against one that runs nothing and reports nothing, breached is 8 |
